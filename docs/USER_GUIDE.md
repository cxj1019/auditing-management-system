## 一、系统简介

本系统面向会计师事务所的日常运营,覆盖业务全生命周期:

> **建档客户 → 立项目 → 签合同 → 开发票 → 收款核销**,以及贯穿其中的**报销、日程工时、函证、成本分析**。

系统按"**项目归属部门**"隔离数据:每个项目登记时确定归属部门,该部门内所有成员共同维护项目相关的合同、发票、函证、收款与报销;系统管理员可见全部;客户信息全员共享。

技术形态:浏览器访问(支持手机浏览器),无需安装客户端。

## 三、角色与权限体系

### 3.1 角色

系统内置 5 个角色(系统管理 → 角色管理可调整):

| 角色 | 定位 |
|---|---|
| 系统管理员 | 系统配置与全部数据(日常业务一般不用 admin 做) |
| 合伙人 | 部门负责人,业务全流程 + 报销终审 |
| 经理 | 业务骨干,业务全流程 + 报销一级审批 |
| 财务 | 专注收付款与报销财务环节 |
| 普通员工 | 填报报销、录入日程、维护客户与项目等基础工作 |

### 3.2 菜单与按钮权限一览(当前线上实际配置)

| 功能 | 管理员 | 合伙人 | 经理 | 普通员工 | 财务 |
|---|:-:|:-:|:-:|:-:|:-:|
| 首页(工作台) | ✅ | ✅ | ✅ | ✅(不含经营数据) | ✅(不含经营数据) |
| 客户管理 | 全部 | 全部 | 全部 | 全部 | — |
| 项目管理 | 全部 | 全部 | 全部 | 全部 | — |
| 合同管理 | 全部 | 全部 | 全部 | 全部 | — |
| 发票管理 | 全部 | 全部 | 全部 | 全部 | — |
| 收款管理 | 全部 | 全部 | 全部 | 仅查询 | 全部 |
| 报销管理 | 全部+类别设置 | 全部+审批+终审 | 全部+审批 | 提交/编辑/撤回(无审批) | 财务操作+审批 |
| 函证管理 | 全部 | 全部 | 全部 | 全部 | — |

| 汇率牌价 | ✅ | ✅ | ✅ | ✅ | — |

> - 普通员工在收款管理中**看不到登记/编辑/删除按钮**,只能查询。
> - 报销的"终审"只有**合伙人或系统管理员**可以做(见报销流程)。
> - 普通员工的工作台不显示收入/成本等经营数据。
> - 角色授权由管理员在"系统管理 → 角色管理"中随时调整。

### 3.3 数据权限(谁能看到哪些业务数据)

业务数据(项目/合同/发票/收款/报销/函证/成本)按**项目归属部门**隔离:

| 身份 | 可见范围 |
|---|---|
| 系统管理员 | 全部 |
| 部门成员(有部门) | 本部门项目的全部相关数据;**未关联项目的报销单对本部门可见** |
| 未分配部门的用户 | 仅自己创建的数据 |

例外说明:

- **客户信息全员可见**(客户不归属部门)。
- **日程**按参与人隔离,不看部门。
- 部门内成员天然可以互相处理项目相关单据(编辑/核销/审批),无需逐条授权。

### 3.4 按钮权限

每个页面的"新增/编辑/删除/审批"等按钮由角色-菜单授权控制;即使按钮被隐藏,直接调用接口也会被后端拒绝——权限是服务端强制的。

## 四、核心业务流程总览

### 4.1 收入主线(项目收费)

```
登记客户 → 登记项目(选归属部门) → 签订合同 → 登记发票(挂合同) → 登记收款(核销发票)
```

1. **客户**:录入工商信息与开票六要素(开票抬头/税号/开户行/账号/地址/电话)。
2. **项目**:关联客户,选择业务类型(决定合同字号),**选择归属部门**。
3. **合同**:选择项目后自动带出业务类型与合同字号(如"迈伊兹审约(2026)第0001号");填不含税金额与税率,含税金额自动算。
4. **发票**:选择合同(草稿合同不可选),价税合计/不含税/税额联动;**开票动作**后进入已开票。
5. **收款**:按发票核销,或先挂合同(预收);核销汇总、合同汇总、垫付台账三个视图对账。

### 4.2 报销流程

```
申请人:填报费用明细 → 保存草稿 → 提交
    ↓
一级审批(经理/合伙人):批准 / 驳回
    ↓ 金额>5000 且审批人非合伙人/管理员
终审(合伙人/管理员):批准 / 驳回
    ↓
财务:确认收到发票 → 标记已付款
```

- 驳回的单子申请人可**修改后重新提交**或删除;待审批的可**撤回**回草稿。
- 提交、审批、转终审都会产生**站内通知**(详见第六章)。

### 4.3 垫付费用闭环(向客户收取)

```
报销明细勾"可向客户收取" → 登记发票勾"垫付开票"(挂同一合同) → 收款核销
                ↓                    ↓                  ↓
        收款管理-垫付台账自动推进:待开票 → 待收回 → 已结清
```

### 4.4 日程与工时

在日程管理按日历登记任务(可选关联项目、可一次指派多人),系统按规则折算工时,成本分析出具人员工时明细。

## 五、各功能模块详解

### 5.1 工作台(首页)

- **待办计数**:待审批报销、待开票发票、逾期应收、逾期函证、即将到期合同。
- **经营数据**(仅管理员/合伙人/经理可见):收入、成本、毛利概览。
- 点击卡片跳转对应模块。

### 5.2 日程管理

- 日历视图按日期登记;**不同日程不同颜色**;可一次为多人创建。
- 可关联项目(用于工时归集)。
- 工时规则:**全天 7 小时**(9:00–17:00,扣除午休);加班每满 4 小时强制扣除 1 小时休息,不计工时。
- "工时统计"页签按人员汇总(需 `工时统计` 权限)。

### 5.3 客户管理

- 详情分**基本信息 / 开票信息 / 联系人**三个页签;联系人可无限添加(姓名必填,可填职务/电话/邮箱/备注)。
- 客户全员可见;开票信息在登记发票时自动带出。
- 列表行点击弹出**客户详情抽屉**。
- "对账单"按钮:一键导出该客户的 Excel 对账单(汇总 / 合同 / 发票 / 回款四个 Sheet),用于与客户核对。

### 5.4 项目管理

- 登记时:**客户必选、归属部门必选**(默认创建人部门)、业务类型从字典选择;**项目期间可不填**(填了校验先后顺序)。
- **归属部门决定数据可见范围**,编辑时可调整,后续单据跟着走。
- **报告登记**:点行内"报告"按钮,登记报告文号、出具日期、签发合伙人;列表可用"仅看已出报告"筛选——项目全生命周期(立项→合同→报告→回款)由此闭环。
- 项目归档后:新增报销/合同/日程/函证/发票时**不再出现在下拉中**;已产生的单据不受影响。
- 已完成的可重新打开;进行中的项目无合同时可删除。

### 5.5 合同管理

- **合同字号自动编号**:格式"迈伊兹×约(年份)第NNNN号",×由业务类型对应的字号类型决定(审/验/咨/代/评/商),流水按"字号类型+年份"独立递增。业务类型在"系统管理 → 业务类型字典"维护(含开票品名/税收分类,开票时自动带出)。
- **金额口径**:以**不含税金额**为主输入,填税率后含税金额、税额自动计算(也可手改任一项,互相联动)。
- 状态机:`草稿 → 执行中 → 已完成 / 已终止`。
  - 草稿:可编辑、可删除;
  - 执行中:不可编辑,可"完成/终止",**才能被发票和收款关联**,纳入到期提醒;
  - 已终止:可删除(有发票或收款关联时不可删);已完成不可删。
- 签约日期可选;不填时编号年份按当前年份。
- 外币合同:选币种后按中国银行牌价自动折算人民币含税金额。

### 5.6 发票管理

- 发票必须挂合同;开票后收款才能按发票核销。发票**金额不受合同金额限制**(垫付费用可继续在同一合同下开票)。
- **价税联动**:与合同同口径,不含税/税率/税额互相推算;外币按牌价折算。
- **垫付开票**:勾选后发票计入"垫付台账"(见收款管理)。
- 发票号可不填(显示"待补号"),开票后建议尽快补录。
- **应收账龄**:工具栏"应收账龄"弹窗,按 0-30 / 31-60 / 61-90 / 90+ 天展示未收余额与张数,90 天以上标红。
- 状态:待开票 →(开票)→ 已开票 →(作废)→ 已作废;扫描件可上传 PDF/图片,支持在线预览与下载。

### 5.7 收款管理

四个页签:

1. **收款记录**:登记收款。两种性质:
   - **核销收款**:挂一张已开票发票;
   - **预收收款**:暂挂合同(草稿合同不可收),日后可核销到发票。
2. **发票核销汇总**:每张发票 已开票金额 vs 已核销金额。
3. **合同汇总**:按合同看 合同金额 / 已收合计 / 未收余额 / 进度条(允许超收,余额为负)。
4. **垫付台账**:按项目归集"垫付合计 → 已开票 → 待开票 / 已收回 → 待收回 / 状态(待开票、待收回、已结清)"——垫付费用的闭环对账看这里。

### 5.8 报销管理

**新建/编辑**(弹窗三要素):

- **报销标题**:如"8月差旅报销"。
- **默认项目**:新费用行的默认归集项目(整单一个项目时填它即可)。
- **费用明细**(可加多行):
  - 类别:字典管理(管理员可在"类别设置"中增删改,见下);
  - 金额、费用日期、事由说明、发票号;
  - **发票类型**:不涉及 / 增值税专票(勾选"增值税专票"复选);**专票必须填税率**;
  - **税率**:预设下拉(13/9/6/3/1.5/0),支持自定义;**税额**默认按 金额÷(1+税率)×税率 自动算,**可手填覆盖**(如机票行程单按票面税额,机建费不参与抵扣);
  - **归集项目**:默认随单头,跨项目费用在此行单独选择;
  - **可向客户收取**:垫付性质的费用勾选,提交后计入垫付台账;
  - 行级发票附件:保存草稿后可按行上传。
- 合计行显示总金额与"其中可向客户收取"金额。

**审批流**(详见 4.2):

- 提交后实时通知审批人;审批后实时通知申请人;金额超 5000 元转**终审**(合伙人/管理员)。
- 待审批可撤回;已驳回可编辑重提或删除。

**财务环节**:已批准的单子,先"确认收发票"再"标记已付款"。

**类别设置**(仅系统管理员):维护费用类别字典(增删改/停用/排序);停用的类别不出现在新单下拉,历史单据不受影响。

**导出**:按费用日期区间导出费用明细 Excel(含发票类型/税率/税额/归集项目)。

**移动端审批**:手机浏览器访问 `/m/approval`,卡片式待办列表,点开明细、一键批准/驳回(可填意见)。

### 5.9 函证管理

登记函证(必须关联项目),跟踪状态:发出 → 回函;逾期(发出超期未回)自动提醒经手人;支持附件。

### 5.10 汇率牌价

查询中国银行外汇牌价(当日/历史),支持按日期查询。合同、发票的外币折算会自动使用牌价数据。

### 5.11 成本分析(管理员/合伙人/经理)

- **项目利润**:按项目统计 合同金额 / 收入(不含税) / 直接成本(不含税) / 人工成本 / 毛利与毛利率;支持年份与关键字筛选。
  - 收入口径:收款按 发票税率→合同税率 价税分离,未设税率按全额;
  - 成本口径:报销专票按不含税计入(可手填税额),其余全额;垫付费用照常计入;
  - 报销成本按"明细行项目优先、随单头兜底"归集。
- **人工成本**:登记人员月度人工,计入项目。
- **费用统计**:已批准报销按 申请人 × 类别 汇总(年份筛选,可导出 Excel)。
- **人员工时明细**:项目 × 人员的工时投入。
- 收入成本明细可整体导出 Excel。

### 5.12 系统管理(仅系统管理员)

- **用户管理**:增删改用户(邮箱即登录账号,统一小写),分配角色与部门,启用/停用。
- **角色管理**:为角色勾选菜单与按钮权限。
- **菜单管理**:维护菜单树与权限标识。
- **部门管理**:维护 G1/G2/G3 等部门(项目归属部门、数据隔离的依据)。
- **业务类型字典**:三级结构(项目性质 → 项目类型 → 业务类型),决定合同字号与发票品名。
- **审计日志**:记录关键操作(登录/增删改/审批等),可按操作人与时间查询。

## 七、数据口径说明(重要)

涉及钱的数据,系统采用以下统一口径,对账时请以此为准:

1. **合同**:以**不含税金额**为主输入;`含税 = 不含税 ×(1+税率)`。列表中"含税金额"即价税合计。
2. **发票**:登记时填写价税合计,不含税/税额按税率拆分(可手调)。
3. **报销**:
   - 金额为**含税**(价税合计);勾选增值税专票的按 `税额 = 金额÷(1+税率)×税率` 计算进项税(可手填,机票行程单场景);
   - **进项目成本 = 金额 − 税额**(专票);普票/不涉及全额进成本;
   - 归集项目:行项目优先,未填随单头;
   - 勾"可向客户收取"的垫付费用**照常计入项目成本**,同时在垫付台账跟踪收回。
4. **成本分析的收入**:每笔收款按 发票税率(挂发票时)→ 合同税率 价税分离,**未设税率的合同按全额计**——因此**签合同请务必填税率**。
5. **收款允许超过合同金额**(垫付+税点开票场景),合同汇总中未收余额为负属正常,表示超收。

## 八、常见问题 FAQ

**Q1:登录提示成功但停在登录页?**
多为后端正在重新部署或会话过期,强刷页面(Ctrl+F5)重试;若仍不行联系管理员查看后端状态。

**Q2:下拉里找不到某个项目?**
项目按**归属部门**隔离:确认该项目的归属部门与你的部门一致;或项目已归档(归档项目不出现在新增单据的下拉里)。成本分析页的项目同理。

**Q3:新建报销保存时报"系统繁忙"?**
检查费用日期/金额是否填写、专票是否已填税率;若仍失败,把操作时间与页面提示截图给管理员查后端日志。

**Q4:附件上传失败?**
仅支持 PDF/JPG/PNG,单个不超过 20MB;检查网络与文件格式。

**Q5:某张发票想改开票信息?**
发票挂合同后所属合同不可改;品名/税收分类随合同业务类型带出,如需调整请改业务类型字典。

**Q6:已驳回的报销单怎么办?**
在列表点"编辑"修改明细后"重新提交";不需要了可直接"删除"。

**Q7:为什么我看不到"垫付台账/费用统计"?**
收款管理与成本分析对普通员工有限制;费用统计仅管理员/合伙人/经理可见。

**Q8: 忘记密码?**
联系系统管理员在"用户管理"中重置。

## 九、名词解释

| 名词 | 含义 |
|---|---|
| 字号 | 合同编号,格式"迈伊兹×约(年份)第NNNN号",按业务类型的字号类型+年份独立递增 |
| 价税合计 / 含税金额 | 发票或合同的总金额(含增值税) |
| 不含税金额 | 价税合计 ÷(1+税率),计入成本费用的部分 |
| 进项税额 / 税额 | 价税合计 − 不含税,增值税专票可用于抵扣 |
| 垫付 | 事务所先行支付、后续向客户收取的费用(如差旅),勾"可向客户收取" |
| 核销 | 把一笔收款对应到某张发票,冲减应收 |
| 待终审 | 一级审批通过但金额超过阈值(默认 5000 元),需合伙人/管理员最终批准的状态 |
| 归集 | 把费用计入某个项目成本的行为 |
| 账龄 | 发票开票至今未收回的时长(天) |
