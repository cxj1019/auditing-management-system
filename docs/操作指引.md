## 1. 报销（员工最常用）

1. 左侧【费用报销】→【登记报销】：填标题、选项目、加明细行（金额、费用日期、类别；**增值税专票勾选后系统自动算税额**）
2. 发票附件：明细行上传照片/扫码拍照（手机打开可直接调摄像头）
3. 保存草稿 →【提交】→ 经理审批（超过 5000 元自动转合伙人/管理员终审）
4. 批准后财务收票、标记付款
- 改错：草稿可编辑；已提交可【撤回】；已删除的在【回收站】恢复

## 2. 对公付款

1. 【对公付款】→【登记付款】：供应商从下拉选（新供应商直接输入，之后在"供应商"页补充资料），金额填**含税额**选税率，系统自动算不含税
2. 提交 → 经理/合伙人批准 → 标记已付款
3. 进项发票页登记供应商发票，付款可【核销发票】（预付抵扣）
- 只有草稿/已驳回能编辑；员工不能撤回已提交的单，请经理驳回后删除重建

## 3. 函证（自动识别）

1. 扫描仪把多份函证扫成一个 PDF（每份通常 3 页）
2. 【函证管理】→【智能批量导入】→ 上传 PDF：AI 自动识别每页"被函证单位"并分组、建议项目
3. 在确认界面核对分组、指定项目 → 确认归档：自动按页拆分挂到各项目函证下
- AI 没认出来的页会归入"未识别单位"，手动指定项目即可，不会丢数据
- 免费池高峰时限流，识别失败等一两分钟重试；**单份 3 页以内最稳**

## 4. 项目工作台

【项目管理】→ 进入项目：合同额、回款、发票、费用成本、人工成本、函证进度一屏全览；可直接开票、登记收款、处理函证。
成本口径：收入按实收回款价税分离；费用成本 = 已批准报销（不含税）+ 已批准/已付对公付款（不含税）+ 手工人工。

## 5. 日程与工时

【日程管理】：周视图排班、月度锁定（仅管理员）、经理确认成员工时。工时 × 级别单价自动计入项目人工成本（级别单价在【成本分析】维护）。
